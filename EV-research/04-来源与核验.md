## 3. 冲突与容易误读的内容

| 问题 | 处理方式 |
|---|---|
| 早期剧本与当前官方背景时间不同 | 见设定文档的版本差异；保留来源版本，优先当前官方影片页 |
| E.V.、Evie、E.V.I.E. 混用 | 保留媒体写法；不自行展开字母含义 |
| 工作台图片被称为“EV 界面” | 只记录图片实际可见内容；未确认的界面归属写明限制 |
| 扫描场景被当成 EV 本体 | 标为场景参考，不能据此确认设备归属 |
| 演员肖像被当作 EV 外观 | 未纳入剧中形象图片 |
| 同人项目自称“电影中的 EV” | 统一标为 R 类，不作为官方源码、UI 或能力证明 |
| 多家报道反复引用同一导演批注 | 不把转载数量当成多份独立证据 |
| 媒体对性格与情绪的解读 | 与可观察功能及官方技术设定分开 |
