# 面向个人助理项目的参考

本文件是对资料的产品抽象，不属于电影官方设定。

## 1. 可以提取的方向

| 资料中的方向 | 个人电脑版可验证的行为 |
|---|---|
| 设备检查与执行反馈 | 运行项目命令，显示日志，检查结果后回报 |
| 当前目标与画面分析 | 先理解用户主动提供的文件和项目上下文 |
| 工作台使用场景 | 界面同时呈现任务、状态和输出位置 |
| 语音伴随与及时提示 | 短句回复、分句播报、任务完成通知 |
| 数据 HUD | 采用清楚的状态、进度、标记与结果展示；视觉参考见 IMG01 |

长期记忆、安卓远程访问、自制手表、权限模型和后台调度，是本项目自行设计的能力，不能声称已获电影技术实现证明。

## 2. 视觉参考的边界

可以从 IMG01 研究青蓝色叠层、橙黄色重点、目标连线和窗格层次；PC 版仍需根据真实任务选择信息。

本轮没有找到可确认的官方 EV 独立头像或完整桌面 UI。球体、面孔、波形核心等方案需要作为原创设计标注。

## 3. 同人软件线索

下表仅记录作者 README 的自述，不代表经过运行验证，也不作为推荐安装结论。

| 项目 | 阅读到的内容 | 状态 |
|---|---|---|
| [Ouru77/ev-assistant](https://github.com/Ouru77/ev-assistant) | 作者描述为 EV 启发的桌面语音助理，涉及 Whisper、Ollama、Electron 与控制台视觉 | 已读取部分 README；该 UI 是同人实现 |
| [Alan-Betty/EV](https://github.com/Alan-Betty/EV) | 当前 README 名称为 L.E.O.，描述应用、文件、命令和浏览器操作，并保留旧 EV 配置迁移说明 | 已读取部分 README；仓库名与当前产品名不同 |
| [wasmiester/NOVA](https://github.com/wasmiester/NOVA) | 作者将 EV 列为灵感，描述 Windows 语音、应用操作和记忆功能 | README 标为开发中；功能自述未实测 |

没有克隆、安装或运行这些项目，也没有把它们的截图混入电影图片目录。后续若选取代码，需要另行核对许可证、依赖与执行权限。
